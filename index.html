Flagship Project

AquaCalm AI — Real-Time Voice Assistant

Full production-grade voice AI system. Speech-to-text captures audio, Claude LLM processes intent and generates responses, TTS synthesizes with optional voice cloning — all streamed via WebSocket token-by-token before audio rendering begins.

REST API supports both audio and text modes with graceful error fallback at every layer. Custom SQLite ConversationStore maintains full session context across turns.
